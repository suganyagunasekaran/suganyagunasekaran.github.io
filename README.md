# Suganya Gunasekaran - Senior Flutter Portfolio

Portfolio built with Flutter Web and prepared for GitHub Pages.

## Run
flutter pub get
flutter run -d chrome

## Build
flutter build web --release --base-href /

## GitHub Pages
Create `suganyagunasekaran.github.io`, push this project to `main`, and set
Settings → Pages → Source to **GitHub Actions**.

## Portfolio content
The professional summary, skills, experience, achievements and education are based on
Suganya Gunasekaran's supplied resume. Personal contact details are included because
they were present in the supplied resume.
